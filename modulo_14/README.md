# Estilo Livre - Exercício Bootstrap

Projeto acadêmico desenvolvido para praticar Bootstrap.

## Recursos utilizados

- HTML5
- Bootstrap 5.3.8 via CDN
- Grid System
- Navbar responsiva
- Cards
- Carousel
- Formulário
- Classes utilitárias
- CSS personalizado
- Responsividade

## Estrutura

```text
estilo-livre/
├── index.html
├── css/
│   └── style.css
└── img/
    ├── hero.svg
    ├── sobre.svg
    ├── corte.svg
    ├── barba.svg
    └── combo.svg
```

Abra o arquivo `index.html` no navegador para visualizar o projeto.
